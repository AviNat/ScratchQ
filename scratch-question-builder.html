Tests

Each test runs the program once: from the green flag, with these values. Empty values: the program's own. A hidden test is graded but its details are not shown to the student.

The grade: the share of the tests passed (each test counts the same). A teacher mistake (tab 3) can set another grade.

A student attempt - graded live

Work as a student would: the palette of tab 1, the starting program and locks of tab 3.

The starting program

What the student starts with: part of the program to complete, or a program with a bug to fix. Leave blocks out, or change them. Locks: right-click a block - 🔒 Lock (the student cannot move or delete it), 🔒 Lock with its values (nothing in it can change), or the whole script. Locked blocks have a dashed outline (red: values locked too). The student may still put new blocks between locked ones.

Common mistakes

A wrong program a student may write. When a student's program gives the same outputs on every test, the student gets your message first (and the grade you set, if any). Matching is by behaviour, so any program with the same mistake matches.

Mistakes in a trace question

Planned: the built-in misconceptions (a loop one time too few or too many, lists counted from 0, …) and wrong answers typed by the teacher. Not in this version.

The exercise file (.scratchq)

The file holds everything the builder needs. The question code (tab 5) is separate. Open also reads a question code saved before.

Scratch files (.sb3)

Import takes the scripts of one sprite and its variables and lists. Export opens in Scratch (File → Load from your computer) - to run the program there.
